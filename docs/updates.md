# 📢 Project Updates & Changelog

Stay up-to-date with recent changes, planned features, and ongoing work across the NjiaSalama ecosystem.

---

## 📌 Latest Updates

### 🚀 Alpha 2.0 Cycle (Active Development)
- **Real-Time WebSocket Integration**: Instant hazard distribution across connected drivers using Socket.IO.
- **Offline Sync Queue**: Users can report potholes and obstacles without cellular data; reports are saved to disk (`offline_pins.json`) and synchronized once back online.
- **Image Upload Support**: Support for uploading photo evidence along with danger pins.
- **Google OAuth Integration**: Added fast sign-in using Google accounts alongside traditional credential auth.

---

### 🛣 Upcoming Roadmap
